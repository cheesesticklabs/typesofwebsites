SAVING AND SUBMISSION
Drafts save in the same browser, device, and file/address. No student drafts are
included in this package. Moving or renaming the HTML may change its draft storage.
Submit sends responses and annotation data to the learnball-25d68 Firebase project,
collection lesson_submissions. Wait for the page to show a confirmation number.
Internet access and Firestore rules permitting the write are required.
Download annotated record saves all frozen images, exact geometry, comments, and answers in JSON.
Open that file in Review-annotations.html to inspect it offline.
Download answers (plain text) and Print / Save PDF are additional backups.
Older browser drafts need each annotated site reopened once before their first exact submission.

The investigation sites remain fictional examples. The discussion gallery shows clean
copies; it does not synchronize another student's annotations.
